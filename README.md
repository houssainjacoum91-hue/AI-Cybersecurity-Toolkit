# 🛡️ AI-Powered Cybersecurity Toolkit

A comprehensive toolkit combining Ethical Hacking, Cybersecurity, and AI for threat detection and log analysis.

## 📂 Project Overview

This repository contains multiple security-focused Python tools simulating a SOC environment and AI-powered threat prediction.

## 🔍 Included Tools

### 1️⃣ Brute Force Detector
- Detects multiple failed login attempts from same IP

### 2️⃣ Phishing Detector
- Scans logs for phishing keywords and suspicious URLs

### 3️⃣ Hash Checker
- Generates MD5/SHA256 hashes to verify file integrity

### 4️⃣ Threat Predictor (AI)
- Machine Learning model predicts risk based on log patterns

## 🛠 Technologies Used

- Python
- Regex
- Pandas
- Machine Learning (Scikit-learn)

## 🎯 Goal

This project simulates the daily tasks of a SOC Analyst with AI-enhanced threat detection.
